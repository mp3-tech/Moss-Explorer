資訊科學小教室：資料格式大解密

你在表格裡填的每一格文字，電腦其實看不太懂。在把資料交給 AI 之前，工程師必須先把這些資料整理成一種固定的格式，才能讓程式順利讀取。這裡介紹你在按鈕上看到的兩種最常見格式：

CSV（逗號分隔值）——給 AI 訓練用

你可以把 CSV 想成「用逗號隔開的超陽春 Excel」。每一筆樣本佔一行，欄位之間用逗號分開，長這樣：

樣本編號,生長型態,顏色,孢蒴
MOSS-001,墊狀,深綠,1
MOSS-002,叢生,黃綠,0

注意到了嗎？「有孢蒴」被換成了 1，「無孢蒴」被換成了 0。這個把文字換成數字的過程，叫做資料編碼 (Data Encoding)。因為 AI 的數學運算只能處理數字，所以必須先把所有答案翻譯成 0 和 1。

JSON（JavaScript 物件表示法）——給程式與資料庫用

如果說 CSV 是「試算表風格」，JSON 就是「標籤清單風格」。每一筆資料都像一個有標籤的小盒子，欄位名稱和數值成對出現，長這樣：

[
  {
    "樣本編號": "MOSS-001",
    "生長型態": "墊狀",
    "顏色": "深綠",
    "孢蒴": "有 (Present)"
  },
  {
    "樣本編號": "MOSS-002",
    "生長型態": "叢生",
    "顏色": "黃綠",
    "孢蒴": "無 (Absent)"
  }
]

JSON 保留了完整的中文標籤，適合讓不同的程式互相傳遞資料，也是下方「從資料庫查詢苔蘚特徵」功能讀取 moss_matrix.json 所使用的格式。

簡單記：要拿去跑 AI 模型 → 用 CSV；要讓網頁或後端程式讀取 → 用 JSON。兩者都是純文字，可以用記事本打開。
