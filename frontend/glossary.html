使用說明： BT上位詞（更廣義的分類）　 NT下位詞（更具體的子類）　 RT相關詞（平行關聯概念）　 USE正式用語（應使用這個詞）　 UF同義詞/舊稱（亦稱為…）

苔蘚植物學術語

關鍵詞 釋義 BT 上位詞 NT 下位詞 RT 相關詞 USE / UF
苔蘚植物 不具維管束、臺灣分布極廣，且適合作為環境指標之植物。 BT 植物界 NT 水苔、泥炭苔 RT 苔球法、物候監測 UF 蘚苔植物
分類學 包含分類、鑑定、描述與命名四大要素之植物科學。 BT 植物學 NT 物種鑑定、命名 RT 苔蘚特徵矩陣 —
苔球法 將苔蘚綁成球狀吊掛，藉由細胞受損狀況偵測空汙的環境監測技術。 BT 環境監測技術 — RT 空氣污染、酸雨監測 —
泥炭沼澤 水苔生長之區域，其分佈位移可作為全球暖化之生態證據。 BT 生態系統 — RT 水苔、全球暖化 —
孢蒴 苔蘚植物用來裝載與散播孢子的器官，長在蒴柄頂端，是辨識物種的重要特徵。 BT 苔蘚植物形態 — RT 苔蘚特徵矩陣 UF Capsule
物候監測 針對生物受氣候影響產生之週期性現象進行長期觀測。 BT 環境科學 NT 遠端物候監測 RT 公民科學、雜訊過濾 —

AI 與資訊科學術語

關鍵詞 釋義 BT 上位詞 NT 下位詞 RT 相關詞 USE / UF
卷積神經網路 利用分層處理與自動學習進行圖像分析之神經網路，是目前影像辨識的主流技術。 BT 人工智慧 — RT 像素分解、圖像分析 USE CNN
像素分解 將影像拆成千萬像素並掃描特徵，以利 AI 學習之技術。 BT 圖像分析 — RT 卷積神經網路 —
苔蘚特徵矩陣 記錄葉型、中肋、邊緣鋸齒等特徵之結構化數據工具，是建立 AI 標籤的科學基礎。 BT 實驗設計 — RT AI 標籤、Quest 3 —
訓練集 符合科學比例（如 8:1:1）分配，用於訓練模型之數據集合。 BT AI 訓練資料 — RT 驗證集、測試集 UF Training Set
過度擬合 模型過度擬合原始數據，導致對新樣本辨識力下降的現象。 BT 機器學習 — RT 比例計算機、驗證集 UF Overfitting
資料集偏差 因收集資料的過程不夠客觀，導致訓練出來的 AI 產生偏見的現象。 BT 機器學習 — RT 訓練集、過度擬合 UF Dataset Bias
特徵萃取 將複雜的原始資料（如高畫素照片），提煉出最關鍵、最具代表性數值的過程。 BT 圖像分析 — RT 卷積神經網路、苔蘚特徵矩陣 UF Feature Extraction
寫作建議： 撰寫科展報告時，第一次提到這些專有名詞，建議在括號內附上英文（例如：假根 Rhizoid），之後再統一使用中文。在文獻搜尋時，可同時使用中文詞條及其對應的 USE 英文術語，以獲得更完整的搜尋結果。
